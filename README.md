One line of software error copy that says what actually broke: the disk is full, the file did not save, and no, the app may not delete your coworkers' files to make room — Legal checked. The program validates the line against the bounty's gate (a single line of 1–200 characters, UTF-8) and writes it to `entry.txt` in the output directory, byte-identical on every run.

## Run it

```sh
python3 main.py
```
